# المحطة — AlMahatta v1.9.0

نسخة نظيفة مجمعة من إصدار التطوير v1.9 بعد اعتماد الواجهة المتجاوبة والرادار وتاريخ اليوم/الشهر/السنة وأوقات الصلاة.

## الملفات

- `index.html` — الواجهة.
- `styles.css` — جميع تنسيقات الواجهة مجمعة في ملف واحد.
- `app.js` — منطق البيانات الأساسي.
- `ui.js` — تحسينات الواجهة، حجم النص، معلومات المصادر، والسحب/التفاعل.
- `radar.js` — الرادار RainViewer والسحب/الرياح Windy وملء الشاشة.
- `config.js` — عنوان API عند فصل الواجهة عن الـWorker.
- `worker.js` — Cloudflare Worker نظيف دون تجربة WU Weather Imagery غير المستخدمة.
- `server.py` — الخادم المحلي.
- `start-local.bat` — تشغيل محلي على Windows.

## المصادر

- القراءات والتوقعات والتاريخ: Weather Underground.
- الرادار: RainViewer.
- السحب والرياح: Windy (تحميل عند الطلب).
- أوقات الصلاة: AlAdhan وفق تقويم أم القرى.

## التشغيل المحلي

شغّل `start-local.bat` أو `python server.py`. إذا كانت `config.js` تشير إلى Cloudflare Worker المنشور فلا يلزم وجود `.env` محلي لعرض البيانات.

## ملاحظات الإصدار

- التبويبات: الحالية، التوقعات، التاريخ، الرادار، أوقات الصلاة.
- التاريخ: يومي/شهري/سنوي؛ الشهري والسنوي يركزان على الحرارة والمطر.
- مطر يونيو 2026 مستبعد من الإحصاءات طويلة المدى.
- الرادار RainViewer مع تخفيف طلبات البلاطات، والسحب/الرياح عبر Windy عند الطلب.
- خريطة الرادار محصورة داخل البطاقة مع ملء شاشة مستقل.
- بطاقة الحرارة الحالية مقسمة 50/50 بين الحالة الحالية والعظمى/الصغرى/المحسوسة.
- حالة الاتصال يحددها لون النقطة؛ النص ثابت وواضح.
- حجم النص: صغير/وسط/كبير مع تكبير النصوص الثانوية فقط.

## الأمان

لا ترفع ملف `.env` إلى GitHub. مفتاح WU يبقى في Cloudflare Secret أو في `.env` المحلي فقط.
