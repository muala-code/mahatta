# المحطة — AlMahatta

Mobile-first weather station dashboard.

واجهة طقس مخصصة للجوال تعرض:

- حالة المحطة الحالية
- توقعات الطقس
- التاريخ اليومي والشهري والسنوي
- أوقات الصلاة
- دعم الوضعين الفاتح والداكن
- دعم العربية والإنجليزية
- تصميم متجاوب مع الوضع العمودي والأفقي

## Data

Weather data is provided through a protected external API service.
No API keys or private credentials are stored in this repository.
